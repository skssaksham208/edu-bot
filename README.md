# 🤖 EDU-BOT

EDU-BOT is an AI-powered chatbot built using React, Vite, Tailwind CSS, and Google's Gemini AI API. It provides intelligent responses to user queries through a clean and modern chat interface.

## 🚀 Features

- AI-powered conversations using Gemini AI
- Modern and responsive UI
- Real-time chat interface
- Loading animations while AI generates responses
- Built with React and Vite for fast performance
- Environment variable support for API security

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Google Gemini API
- React Icons
- React Spinners

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/skssaksham208/edu-bot.git
```

2. Navigate to the project folder

```bash
cd edu-bot
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file in the root directory

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```

5. Start the development server

```bash
npm run dev
```
